LOOP LOGIC
═══════════════════════════════════════════════════════════════════

Skeptic Decision:
  IF approved:
    → Continue to Strategist
  ELSE IF loop_count < max_loops:
    → Loop back to Analyst (iteration++)
  ELSE:
    → Force proceed to Strategist (safety)

Example Flow:
  Iteration 1: Analyst → Researcher → Skeptic ❌ → LOOP
  Iteration 2: Analyst → Researcher → Skeptic ✅ → Strategist
