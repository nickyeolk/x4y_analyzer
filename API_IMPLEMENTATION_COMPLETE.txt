═══════════════════════════════════════════════════════════════════
SSE EVENT FLOW
═══════════════════════════════════════════════════════════════════

Client connects to /api/analyze/stream
    ↓
1. analysis_started
   - Analysis ID generated
   - Correlation ID created
   - Business idea sent
    ↓
2. agent_started (analyst)
   - Agent begins execution
    ↓
3. agent_completed (analyst)
   - Agent finishes
    ↓
4. agent_started (researcher)
    ↓
5. agent_completed (researcher)
    ↓
6. agent_started (skeptic)
    ↓
7. agent_completed (skeptic)
    ↓
[IF LOOP TRIGGERED]
8. loop_triggered
   - Iteration count
   - Loop reason
   - Back to step 2
    ↓
[IF APPROVED]
9. agent_started (strategist)
    ↓
10. agent_completed (strategist)
    ↓
11. analysis_completed
    - Final status
    - Viability score
    - Duration
    - Cost
    ↓
12. result
    - Complete AnalysisResponse JSON
    ↓
Connection closes

USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════

Start Server:
    uvicorn src.api.main:app --reload --host 0.0.0.0 --port 8000

Test Suite:
    python scripts/test_api.py

cURL Synchronous:
    curl -X POST http://localhost:8000/api/analyze \
      -H "Content-Type: application/json" \
      -d '{"x_brand": "Uber", "y_market": "Dog Walkers"}'

cURL Streaming:
    curl -N -X POST http://localhost:8000/api/analyze/stream \
      -H "Content-Type: application/json" \
      -d '{"x_brand": "Netflix", "y_market": "Fitness Classes"}'

Python Async:
    import httpx
    async with httpx.AsyncClient(timeout=300.0) as client:
        response = await client.post(
            "http://localhost:8000/api/analyze",
            json={"x_brand": "Uber", "y_market": "Dog Walkers"}
        )
        result = response.json()
